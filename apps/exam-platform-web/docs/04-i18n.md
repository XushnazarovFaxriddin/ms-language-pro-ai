# 04 — i18n (EN + UZ)

Stack va pattern data-engine-web bilan bir xil (`/apps/data-engine-web/docs/04-i18n.md`).

## Spetsifik talablar

### Talaba tilida feedback
- Foydalanuvchi profilida `locale` saqlanadi
- Imtihon natijasida feedback `locale`'ga muvofiq beriladi (UZ yoki EN)
- LLM scoring API'ga `locale` yuboriladi → prompt UZ/EN feedback so'raydi

### Default locale
- O'zbek tili default (UZ)
- Browser `Accept-Language` header asosida — agar EN birinchi bo'lsa, EN

### Imtihon navigatsiya til
- Test mazmuni (passages, prompts) — har doim **inglizcha** (test ingliz tilini baholaydi!)
- UI navigatsiya, ko'rsatmalar — UZ yoki EN

### Sertifikat
- PDF sertifikatda foydalanuvchi ismi va imtihon natijasi UZ + EN ikkala tilda
- "Common European Framework: B2" + "CEFR darajasi: B2"

## Catalog tarkibi
```
messages/
├── en.json
└── uz.json
```

Asosiy namespace'lar:
- `Common.*` — actions, navigation
- `Exams.*` — exam list, blueprint names
- `Runner.*` — ExamRunner UI strings
- `Results.*` — band labels, criteria names
- `Audio.*` — recorder/player strings
- `Errors.*` — user-facing error messages
