# exam-platform-web

> **Owner**: Faxriddin
> **Stack**: Next.js 15 · TypeScript · Tailwind v4 · shadcn/ui · TipTap · MediaRecorder · Zustand

Student-facing UI: take IELTS/CEFR exams, view results, download certificates.

## Run locally

```bash
pnpm install
pnpm dev --filter exam-platform-web
```
