# data-engine-web

> **Owner**: Bobomurod
> **Stack**: Next.js 15 · TypeScript · Tailwind v4 · shadcn/ui · TanStack Query · recharts

Admin UI for content team: question generation, review queue, calibration analytics, prompt management, **LLM token usage dashboard**.

## Run locally
```bash
pnpm install
pnpm dev --filter data-engine-web
# Or via Turborepo from repo root: pnpm dev
```
