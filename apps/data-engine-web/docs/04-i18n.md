# 04 — i18n (EN + UZ)

## Stack
- `next-intl` (App Router native)
- Locale segment: `/[locale]/...`
- Catalogs: `messages/en.json`, `messages/uz.json`
- Shared with other apps via `@languagepro/i18n` package

## Routing
- `/uz/dashboard` (default)
- `/en/dashboard`
- Middleware redirects `/dashboard` → user's preferred locale

## Translation keys
Namespaced per feature:
- `Dashboard.title`
- `Generation.form.skill_label`
- `LLMUsage.stat_cards.cost_today`
- `Common.actions.save`

## Date / number formatting
`useFormatter()` hook from next-intl:
- Currency: `formatter.number(cost, {style: 'currency', currency: 'USD'})`
- Date: `formatter.dateTime(ts, 'medium')`
- Relative: `formatter.relativeTime(ts, now)`

## Switching language
Top-bar dropdown → updates user prefs (auth-api `PATCH /me`) + cookie + redirects.

## Missing translation policy
- Build fails if translation key referenced but not in JSON
- Fallback: EN (English)

## Plurals
ICU MessageFormat:
```json
"items.count": "{count, plural, =0 {No items} one {# item} other {# items}}"
```

## RTL
Not needed (UZ Latin + EN). Skip `dir=rtl` work.
