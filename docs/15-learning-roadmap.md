# 15 — Learning Roadmap

> **TL;DR.** After every attempt the platform generates a personalised, time-bound roadmap to a target band. Inputs: latest skill bands, error taxonomy hits, vocabulary CEFR coverage, time available, weak phonemes. Outputs: a 4–12-week plan of daily tasks (drills + flashcards + practice exam slots), a target-band prediction with confidence intervals, a spaced-repetition queue, and a weekly check-in. The Roadmap is the engagement loop: it pulls users back to Practice Mode and Mock Tests.

The plan is generated by **`generate_roadmap` arq job** chained after `compile_attempt_feedback`. It uses one Gemini call seeded with all inputs from §1 plus the available drill / lesson catalogue. The model returns a **discrete** plan that's persisted; we never re-prompt for trivial updates.

## 4. Target-band prediction (Monte-Carlo)

We don't promise the user "you will get 7.0". We give a **range** with confidence.

Inputs:
- Current band estimate (latest attempt)
- Historical lift per week from cohort data (e.g. median +0.1 band/week for users at this baseline)
- Per-skill weakness sizes
- User's available hours

Method:
- 10 000 Monte-Carlo simulations sampling from cohort distributions weighted by similarity.
- Output: P10, P50, P90 of band-at-target-date.
- Updated weekly based on observed practice + mock results.

UI: ribbon chart with the predicted band over time; current point + the three confidence levels fanned out.

Cohort building: `analytics.cohort_stats_mat` (materialised view) refreshed nightly. Joined keys: `(starting_band_bucket, target_skill, weekly_hours_bucket)`.

Algorithm: **FSRS-4** (Free Spaced Repetition Scheduler) — open-source, scientifically validated, beats classic SuperMemo SM-2 on retention.

| ref_id | TEXT |

| reps | INT |

## 6. Drill + lesson catalogue

`data_engine.drills` (seed + admin-edited):

| col | type |
|---|---|
| id | UUID PK |
| code | TEXT UNIQUE (e.g. `reading_skim_main_idea_v1`) |
| skill | TEXT |
| target_codes | TEXT[] (FK error_taxonomy.code) |
| cefr_level | TEXT |
| duration_minutes | INT |
| payload | JSONB (instructions, example items) |
| variant_count | INT (how many randomised instances exist) |
| created_at | TIMESTAMPTZ |

The roadmap planner picks drills by:

1. Most-frequent error codes from the user's last attempt.
2. Filter by `cefr_level` ≤ user's current band proxy (e.g. band 5.5 → B1).
3. Mix in 20% above-level drills for stretch.

Drills are surfaced in [`16-practice-mode.md`](16-practice-mode.md).

## 7. Weekly check-in

Every 7 days the user gets:

- An email + in-app banner asking them to take a 10-minute mock to recalibrate.
- The mock targets the **weakest** skill from the latest attempt.
- After the mock, the roadmap recomputes (band prediction + remaining milestones).

Skipping: 2 missed weeks → roadmap status downgrades to `at_risk`; the planner inserts a "comeback" week with lighter load.

## 10. Algorithms (dissertation-relevant detail)

### 10.1 Cohort similarity

```
similarity(user_a, user_b) = exp(-||x_a - x_b|| / τ)
where x = [starting_band, weekly_hours, days_active, target_band, focus_skill_onehot]
```

Top-K cohort (`K = 200`) drives MC simulation. τ tuned offline to maximise prediction calibration.

### 10.2 Adaptive lesson selection

For each upcoming day, the planner solves a small ILP:

- Maximise: ∑ relevance_score(drill_i) × selected_i
- Subject to: ∑ duration_i × selected_i ≤ daily_minutes
- Coverage constraint: at least one drill targets each of the top-3 weakest error codes within a week
- Variety: no drill repeats within 3 days

Solved with `pulp` or a greedy heuristic if cluster size < 10.

### 10.3 Band-prediction calibration

Calibration measured on the held-out cohort:

- For users whose target date passed, compare predicted P50 vs actual band.
- ECE (Expected Calibration Error) target: ≤ 0.05.
- Weekly retraining of cohort distributions; alert if ECE > 0.08.

This calibration analysis is part of Bobomurod's research output ([`18-research-and-psychometrics.md`](18-research-and-psychometrics.md) §8).

## 11. Acceptance

- [ ] First-time user with target band 7.0 in 8 weeks gets a roadmap with at least 8 weekly milestones, each with ≥ 3 items.
- [ ] After a follow-up attempt, the roadmap regenerates within 30 seconds.
- [ ] FSRS queue produces non-empty results for any user with at least 5 graded cards.
- [ ] Skipping 2 consecutive weeks moves the roadmap to `at_risk` status with a recovery plan.
- [ ] Band-prediction P50 is within ±0.5 of the actual end-state band on 80% of users in the calibration cohort.
- [ ] Switching `me.preferences.focus_skill` from `reading` to `speaking` regenerates upcoming weeks' drills accordingly.
