## ⚠️ MUHIM (Critical) — IELTS / Cambridge content

**Real IELTS, Cambridge English, TOEFL, PTE, Aptis, va boshqa rasmiy imtihon savollari himoyalangan intellektual mulkdir.** Bu kontentlardan **birortasi ham** LanguagePro AI tarkibida takrorlanmaydi yoki nashr etilmaydi.

The platform is positioned as **"IELTS-aligned, CEFR-calibrated"**, NOT as "IELTS test simulator with real questions." All assessment items in our system are either:
- AI-generated and validated by our pipeline (Bobomurod's contribution), OR
- Sourced from explicitly open-licensed datasets listed below.

If we ever quote a few sample questions from official sources for academic comparison, it will be:
1. Limited to "fair use / fair dealing" academic context only,
2. Properly cited,
3. Never displayed to platform users.

## 2. AI-generated content licensing

All questions, prompts, and rubrics produced by `data-engine`'s LLM pipeline:

| Aspect | Status |
|---|---|
| Generated by | Google Gemini 2.x (via OpenAI SDK / OpenAI-compat endpoint) |
| Provider terms | [Gemini API Terms of Service](https://ai.google.dev/gemini-api/terms) |
| Commercial use | ✅ Permitted under standard Gemini API terms (paid tier) |
| Output ownership | The user (us) owns generated content per Google's policy, subject to safety filters. |
| Attribution | Not required by Google; we still log `generated_by_model` in `data_engine.questions` for provenance. |
| Restrictions | Must comply with Google's [Generative AI Prohibited Use Policy](https://policies.google.com/terms/generative-ai/use-policy). No content for: deepfakes, mass-targeted disinformation, unauthorized PII scraping, etc. |

**Provenance tracking**: every AI-generated question stores in DB:
- `generated_by_model` (e.g., `gemini-2.5-pro`)
- `prompt_version_id`
- `generation_run_id`
- `validation_results` (jury verdicts)
- `human_review_decision` (if applicable)

This satisfies academic integrity for the dissertation and gives us a paper trail for any future content disputes.

## 3. Audio assets (listening section)

Listening passages cannot be sourced from official IELTS recordings. Approach:

1. **Phase 1 (MVP)**: Generate transcripts via Gemini, then synthesize speech via Google Cloud Text-to-Speech (Neural2 voices) — terms permit commercial deployment.
2. **Phase 2 (Pilot+)**: Record short passages with volunteer native speakers (BSU language faculty + via Common Voice augmentation) under explicit signed waiver.
3. **Phase 3 (Production-grade)**: Partner with content provider for licensed passages OR build a curated public-domain audiobook excerpt library.

All audio in `S3://audio-prompts` carries metadata:
- `source_type` ∈ `tts | recorded | public_domain | licensed`
- `license` (string)
- `attribution_required` (bool)
- `voice_id` (for TTS)

## 4. User-generated content (UGC)

Student-submitted essays, audio recordings, and answers:

| Aspect | Policy |
|---|---|
| Ownership | Student retains copyright |
| LanguagePro grant | Limited license to: store, process via AI, generate scoring + feedback, anonymize for research, and aggregate for IRT calibration |
| Retention | Audio recordings deleted after 90 days unless student opts in to "research donation" |
| Anonymization | All PII stripped before any export; only `pseudo_id`, `cefr_level`, `score`, `text` retained |
| Researcher exports | Require explicit student opt-in; aggregated stats only otherwise |

User-facing language (in EN/UZ) lives in landing's Privacy Policy + ToS, which must be drafted before pilot (Week 9).

## 6. Per-source detailed entries

### 6.1. CEFR-J Wordlist v1.5

- **URL**: https://github.com/openlanguageprofiles/olp-en-cefrj
- **License**: CC BY 4.0
- **Citation**: Tono, Y. (2013). _CEFR-J Handbook_. Taishukan Shoten.
- **Usage**: We import the CSV into `data_engine.taxonomies.evp_cefr_words` (~12k entries). The CEFR classifier service queries it to compute per-text vocabulary level distributions.
- **Update cadence**: Refresh on every minor version of CEFR-J.

### 6.2. English Vocabulary Profile (EVP)

- **URL**: https://englishprofile.org/wordlists/evp
- **License**: Free for educational use; commercial restricted (Cambridge University Press).
- **Usage**: Used for cross-validation against CEFR-J during classifier development. **NOT shipped in production database.** Only exported summary statistics enter the pipeline.
- **Risk**: If LanguagePro AI is later commercialized, replace EVP-derived signals with CEFR-J-only or license-cleared alternative.

### 6.3. Speechocean762

- **URL**: https://www.openslr.org/101/
- **License**: Apache 2.0
- **Citation**: Zhang et al., "Speechocean762: An Open-Source Non-native English Speech Corpus For Pronunciation Assessment" (2021).
- **Usage**: Used during research/dev only — never ships in production. We benchmark our Gemini-multimodal speaking scoring against Speechocean762 GOP and PCC scores in Faxriddin's evaluation chapter.

### 6.4. Project Gutenberg

- **URL**: https://www.gutenberg.org/
- **License**: Public domain in the US (with the [Gutenberg Trademark license](https://www.gutenberg.org/policy/license.html) for the Gutenberg branding only).
- **Usage**: We adapt classic literature excerpts (e.g., Twain, Conan Doyle) into B1–C1 reading passages via LLM rewrite. Each adaptation stores `source_url`, `source_license=PD-US`, `adapted_via_llm=true`. We do not display Project Gutenberg branding; we attribute as "Adapted from public-domain text by [author]."

### 6.5. Wikipedia

- **URL**: https://en.wikipedia.org/
- **License**: CC BY-SA 4.0 (Share-Alike)
- **⚠️ Warning**: Share-Alike means any derivative work must also be CC BY-SA. **We avoid Wikipedia for the main reading-passage corpus** to prevent cascading our entire pipeline into CC BY-SA. We instead use Wikipedia only as a *fact-checking source* for AI-generated passages (one-time read, not stored).
